# Anvil Capture

**Capture anything. Find it again instantly.**

Anvil Capture is a local-first Windows capture and visual-memory utility combining screenshots, OCR, searchable history, clipboard history, scrolling capture, screen recording, annotations and step-by-step documentation.

## Download

Download the latest Windows release from:

**Releases → Latest Release**

Windows 10/11 · 64-bit

## What Anvil Capture Does

- Region, window and display screenshots
- Searchable OCR
- Copy text directly from your screen
- Scrolling screenshots
- Searchable clipboard history
- Image clipboard history
- Screenshot annotation and redaction
- Screen recording
- Step Capture documentation
- Favorites
- Fast local search
- Global keyboard shortcuts
- System tray integration

## Search Everything

Press **Alt+V** to quickly search your screenshot history, OCR content and clipboard history.

## Copy Text From Anywhere

Press **Ctrl+Shift+X**, select an area of the screen, and Anvil Capture extracts the text locally.

## Step Capture

Create visual walkthroughs and documentation by capturing a sequence of actions and exporting the finished guide as PDF, HTML or Markdown.

## Local-First

Screenshots, OCR results, clipboard history and the search database are stored locally on your computer by default.

## Anvil Capture Compute

Anvil Capture Compute is the free edition.

After explicit activation, it contributes a small, controlled amount of unused CPU resources to Monero mining operated by Anvil Interactive Solutions.

No mining occurs before the Compute Agreement is accepted.

The Compute system:

- requires explicit consent
- reduces resource usage while you are actively using your computer
- may increase contribution while the computer is idle
- is limited to a configured maximum CPU contribution
- pauses during demanding Anvil Capture operations
- pauses on battery power
- stops when Anvil Capture exits
- remains visible in Windows Task Manager
- can be revoked from the application

Mining proceeds belong to Anvil Interactive Solutions. Users do not receive cryptocurrency.

Read the full disclosure in [COMPUTE_DISCLOSURE.md](COMPUTE_DISCLOSURE.md).
